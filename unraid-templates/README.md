# unraid-templates

Unraid Community Applications template (`medi.xml`) with pre-configured GPU
passthrough tags (`/dev/dri`, NVIDIA runtime) and the `/config` + `/media` volume
mappings, plus `ca_profile.xml` (maintainer metadata + support links). May also live
in a separate GitHub repo. Authored in **Phase 5** (`docs/.tasks/50-phase5-playback-packaging.md`).
